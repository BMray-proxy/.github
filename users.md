# Пользователям

[Главная](https://github.com/BMray-proxy) · [Разработчикам](developers.md)

BMray — прокси-клиент для Android на базе Xray. Для подключения нужна подписка или конфигурация сервера от провайдера.

## Установка и первое подключение

1. Скачайте APK из [последнего релиза](https://github.com/BMray-proxy/BMray-releases/releases). Публичный репозиторий — [BMray-releases](https://github.com/BMray-proxy/BMray-releases). Android 0.4.9 опубликован: [скачать APK](https://github.com/BMray-proxy/BMray-releases/releases/download/v0.4.9/BMray-0.4.9-android.apk). Вход в GitHub не требуется. Готового IPA для iOS пока нет.
2. Откройте APK на Android и подтвердите установку. При обновлении используйте файл с той же подписью; удаление приложения может привести к потере локальных настроек.
3. В BMray нажмите **«+»**. Добавьте ссылку подписки или сервера; в меню добавления также доступны буфер обмена и QR-код.
4. Выберите сервер и нажмите кнопку подключения. При первом подключении Android попросит разрешить создание VPN.
5. Для отключения снова нажмите кнопку подключения. Также можно отключиться из уведомления приложения.

## Подписки и серверы

- Обновляйте подписку кнопкой обновления в её карточке, чтобы получить актуальные серверы и параметры.
- Выбирайте сервер вручную или используйте сервер с автовыбором, если его предоставляет провайдер.
- **Сервер с автовыбором** содержит несколько направлений внутри конфигурации Xray. Его поведение задаёт провайдер.
- **Автовыбор наилучшего сервера при пинге** — отдельная настройка приложения: проверяет список серверов, сортирует результаты и выбирает доступный сервер с наименьшим пингом. Если VPN уже работает, возможна смена подключения.
- Кнопки сайта подписки, поддержки и Telegram Proxy появляются, когда провайдер передаёт соответствующие ссылки.

## Проверка пинга

В настройках пинга выберите метод проверки:

| Метод | Что проверяет |
| --- | --- |
| Proxy GET | HTTP(S)-запрос через выбранный прокси: проверяет, проходят ли данные |
| TCP | Соединение с адресом и портом сервера; успешный результат ещё не подтверждает работу прокси |
| ICMP | Ответ сервера на эхо-запрос; он может быть запрещён на работающем сервере |

Для **Proxy GET** доступны три режима:

| Режим | Простое объяснение |
| --- | --- |
| Default | Один запрос. В измерение входит установка соединения |
| Keep-alive | Первый запрос подготавливает соединение, второй измеряется. Соединение используется повторно, если это поддерживает сервер |
| Double | Два запроса с отдельными соединениями. Показывается среднее время |

Результат зависит от вашей сети, сервера и адреса проверки. Низкий пинг не гарантирует максимальную скорость скачивания. Отключение сортировки возвращает исходный или сохранённый вручную порядок серверов.

## Раздельное туннелирование

В разделе маршрутизации можно задать правила для доменов и IP, использовать категории GeoIP/Geosite и выбрать приложения, которые работают через VPN или обходят его. После изменения правил переподключите VPN, чтобы применить их к новым соединениям.

## Кастомизация

Откройте **Настройки → Кастомизация**:

- В разделе **«Темы»** выберите цветовую тему. Там же доступны иконки приложения и редактор оформления.
- Включите **«Мини-кнопка VPN внизу»**, если хотите компактное управление подключением в нижней части экрана.
- Выбранная иконка используется в интерфейсе Android и уведомлении приложения.

На рабочий стол Android можно добавить виджет BMray 1×1 для управления подключением. Его цвет показывает состояние VPN. Разрешите уведомления, чтобы видеть подключённый сервер и пользоваться действиями пинга и отключения.

## Telegram Proxy

Если провайдер передаёт заголовок ответа `tgproxy-url`, в карточке подписки появляется отдельная кнопка Telegram Proxy. Она размещается рядом с Telegram-поддержкой, а при отсутствии ссылки поддержки занимает её место. Нажатие открывает ссылку провайдера в Telegram или другом подходящем приложении.

Провайдер может показывать эту кнопку только при истёкшей или отключённой подписке. Наличие кнопки зависит от ответа сервера при обновлении подписки.

## Если появилась ошибка

| Сообщение | Что делать |
| --- | --- |
| HTTP 403 | Сервер запретил доступ. Уточните причину у провайдера |
| HTTP 404 | Проверьте ссылку подписки или запросите новую |
| HTTP 429 | Подождите перед следующим обновлением |
| HTTP 502 / 503 / 504 | Повторите позже; при повторении сообщите провайдеру код и время |
| DNS | Проверьте подключение и доступность домена подписки |
| TLS | Проверьте дату и время устройства; сообщите провайдеру об ошибке сертификата |
| Тайм-аут | Сервер не успел ответить; попробуйте другую сеть или повторите позже |

Код ответа показывает результат запроса, но сам по себе не объясняет причину отказа. Для обращения за помощью укажите версию BMray, Android, точный текст ошибки и действие, при котором она появилась. Ссылки подписок, ключи и пароли публиковать не нужно.
